# Mula–Mutha historical silt analysis

The Silt Analysis dashboard now has a Historical Silt Analysis section under the existing cross-section, silt profile, and Area & River Bed Data panels. It reads the stored monthly classification and volume rasters for the selected bank only. Months without a raster stay blank.

## Files inspected

- `src/data/siltPeriods.generated.js` — month index generated by `scripts/ingestRiverISlit.mjs`
- `public/data/hydrology/silt/classification/YYYY-MM/` and `public/data/hydrology/silt/volume/YYYY-MM/` — `overlay.png`, `legend.png`, `meta.json`
- `src/scene/siltAreaAnalysis.js` — live polygon sampler. Classes come from the palette. The volume surface is colour-decoded. `volumeM3` stays unavailable because there is no thickness layer. The dashboard already shows `volumeIndex.total` as m³, “relative 1 m layer”.
- `src/scene/hydrologyLayer.js` — `SILT_VOLUME_MAX = 94.31`, class labels Low / Moderate / High / Very High
- `src/ui/components/siltAnalysisOverlay.js` and `src/styles/silt-pro.css` — existing dashboard, edge buttons, dark teal panels

`meta.json` stores bounds and the source KML name. It does not store a monthly cubic-metre table. There is no separate per-section history table.

## Data sources

Each month is a GroundOverlay pair:

- Classification overlay, decoded with the same hue rules as the live analysis (Low, Moderate, High, Very High).
- Volume overlay, decoded against that month’s legend ramp (0–94.31). The legend unit is unconfirmed in the source. The chart uses the same summed cell index the live panel already labels m³, “relative 1 m layer”.

A cell inside the four-point polygon is counted for the bank it is nearest to (P1→P2, P2→P3, P3→P4, or P4→P1). The four sections are not averaged. On the test polygon the four November 2026 section volumes were 2,432 + 3,393 + 7,517 + 5,236 = 18,578 m³, matching the live polygon total of 18,577.87 m³.

## Monthly raster availability

The same files cover the whole silt corridor. A section can still have no decodable cells inside its own part of the polygon.

## Graph implementation

- `summarizeSiltEdges()` in `src/scene/siltAreaAnalysis.js` samples one stored month and returns four edge totals. It does not build the live clip, hotspots, or 3D surface.
- `src/ui/components/historicalSilt.js` loads every stored month once per polygon, keeps a year selection that does not change the bank, and draws three SVG charts plus the comparison strip.
- Volume: bars, m³ axis. Bright bar = highest valid month, gold outline = lowest. Blank columns are not zeros and are not joined.
- Coverage: line and points, percent axis. The line starts again after a missing month.
- Classification: stacked percent bars. Low `#22c55e`, Moderate `#a3c400`, High `#f97316`, Very High `#ef4444`. A class with no cells in a measured month is 0%. A month with no classification is N/A.
- Hover shows month, year, section, volume, coverage, covered area, section area, class split, change from the previous available month, and provenance.

## Comparison

Latest stored month in the selected year versus the previous month in that year that has a value. Missing months are skipped, not treated as zero and not treated as the next consecutive measurement.

- Volume difference = current − previous available
- Percent = difference / previous × 100. If the previous volume is 0 or missing, the percent is N/A.
- Coverage difference is in percentage points, using the previous month that has coverage.

Increase is an orange upward marker. Decrease is green. No change is neutral. The strip names the months, for example “November 2026 compared with October 2026.”

## Limitations

- The cubic-metre figure is the colour-decoded volume surface summed on the section, same convention as the live “relative 1 m layer” total. It is not a surveyed thickness volume. `volumeM3` in the analyzer remains unavailable.
- Section area is the raster cells inside the polygon nearer to that bank, not a stored polygon area.
- Some stored volume months do not decode inside a given section. Those stay blank.
- Raster presence is shared by the corridor. Counts, coverage, class mix, and decoded volume change with the polygon and the selected bank.
- The live silt pipeline, 3D surface, and the three existing dashboard panels were not replaced.
